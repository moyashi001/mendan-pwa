# 面談管理（PWA ＋ スプレッドシート）

社内面談の日程調整をスマホで行う PWA。面談者（管理者）が面談枠を作り、メンバーが第1・第2希望を選んで送信し、面談者が日時を確定する。データは Google スプレッドシートに保存され、GAS（Google Apps Script）が中継する。

```
PWA（Vercel） ⇄ GAS（Webアプリ） ⇄ スプレッドシート
```

## 画面
- **メンバー画面**：名前を選ぶ → 面談枠から第1希望（必須）・第2希望（任意）を選んで送信。確定するまでは選び直せる。確定後は面談日時を表示する
  - ほかの人の希望は、枠ごとの人数（第1・第2）だけ表示する。ほかの人で確定した枠は「埋まりました」となり選べない
  - 過ぎた日の枠は表示しない
- **管理者画面**（右上の「管理」→ パスコード）
  - 希望・確定：確定／確定待ち／未回答の人数と一覧。タップして確定（希望以外の枠も選べる）・確定の取り消し。第1希望の重なりやほかの人の確定を警告する
  - 面談枠：日付・開始・1枠の長さで追加。終了を入れると、まとめて区切って作る（同じ時刻の枠は飛ばす）。削除すると、その枠を希望していた人の希望から外し、第2希望を第1希望に繰り上げる。確定済みの枠は削除できない
  - メンバー：社員番号・名前の追加・編集・削除（どちらも重複不可）

## セットアップ

### 1. スプレッドシートと GAS
1. Google ドライブで新しいスプレッドシートを作成する
2. 「拡張機能 > Apps Script」を開き、`gas/Code.gs` の内容を貼り付けて保存する
3. 関数 `setup` を選んで「実行」する（初回は権限の承認が必要）
   - 「メンバー」「面談枠」「設定」「変更履歴」のシートが作られる
4. 「設定」シートに次の内容を書く
   - 面談名：画面タイトルに使う（例：上期）。空欄なら「面談管理」とだけ表示する
   - 管理パスコード：管理者画面に入るためのパスコード（必須）
5. 「デプロイ > 新しいデプロイ」から次の設定でデプロイする
   - 種類：ウェブアプリ
   - 次のユーザーとして実行：自分
   - アクセスできるユーザー：全員
6. 表示された URL（末尾が `/exec`）をコピーする

### 2. PWA
1. `config.js` の `GAS_URL` に、手順 1-6 の URL を貼り付ける
2. このフォルダを Vercel などで公開する
3. 管理者画面の「メンバー」タブでメンバーを登録し、「面談枠」タブで枠を作ってから、公開 URL をメンバーに共有する。スマホでは「ホーム画面に追加」するとアプリとして使える

## GAS を修正したとき
「デプロイ > デプロイを管理」で既存のデプロイを編集し、バージョンを「新バージョン」にして更新する（URL は変わらない）。

## 動作テスト
`tests/fake-gas.js` でスプレッドシートなどをモックして `gas/Code.gs` を動かし、`app.js` を jsdom 上でつないで、画面の操作からシートへの保存までを確認する（`tests/app.test.js`）。
```
npm install
npm test
```
テスト関連のファイルは `.vercelignore` で公開対象から外している。

## 注意
- メンバーはログインがなく名前を選ぶだけのため、URL を知っている人はほかの人の名前で希望を出せる。変更は「変更履歴」シートに記録される
- 社員番号は管理者画面だけで扱い、メンバー向けの通信には含めない
- パスコードを続けて10回間違えると、10分間は管理者の操作を受け付けない
- スプレッドシートには社員番号とパスコードが入るため、リンク共有はしない
- 社員番号・日付・時刻はシート上で文字列として保存する（先頭の 0 が消えないようにするため）。シートで直接編集した日付・時刻も読み込み時に形式をそろえる
